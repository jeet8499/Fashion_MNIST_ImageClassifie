# Fashion_MNIST_ImageClassifie
This project demonstrates the implementation and training of a Multilayer Perceptron (MLP) neural network using TensorFlow and Keras to classify images from the Fashion MNIST dataset. The workflow includes data loading, preprocessing (normalization, splitting into training, validation, and test sets), model definition with Flatten, Dense (ReLU activated) hidden layers, and a Softmax output layer. The model is compiled with sparse_categorical_crossentropy loss and sgd optimizer, and trained over 30 epochs. Finally, the model's performance is evaluated, and predictions are made on new, unseen images.
